# Hesap Makinesi

HTML, CSS ve JavaScript kullanılarak geliştirilmiş basit bir hesap makinesidir.

## Özellikler
- Toplama, çıkarma, çarpma, bölme işlemleri
- Yüzde hesaplama
- Klavye desteği
- Hata yönetimi

## Kullanılan Teknolojiler
- HTML5
- CSS3
- JavaScript (Vanilla)
